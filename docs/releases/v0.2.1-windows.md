# MIMI Music Player v0.2.1 — Windows x64 桌面交付说明

## 交付范围

本版本提供 Windows x64 portable EXE 与 NSIS 安装程序。Electron 会启动随包提供的轻量 FastAPI 后端，并在启动时等待 `/api/health` 就绪。模型文件不随安装包预置，也不会在首次启动时自动联网下载。

当前后端明确提供：

- `GET /api/health`
- `GET /api/capabilities`
- 音频、TTS、视觉入口在模型运行时未提供时返回结构化 `501 CAPABILITY_UNAVAILABLE`

因此本版本不会把尚未接入真实推理运行时的 AI 能力标记为已完成。

## 环境要求

- Windows 10/11 x64
- 本地无代码签名；首次运行可能显示 SmartScreen 或 Unknown Publisher 提示
- 便携版无需安装器，安装版通过 NSIS 安装

## 构建

在 Windows PowerShell 中执行：

```powershell
./scripts/build-desktop-win.ps1 -Clean
```

脚本按以下顺序执行：

1. `npm ci`
2. 安装轻量后端依赖和 PyInstaller
3. 构建 `backend/dist/backend.exe`
4. 构建 Next.js 静态产物
5. 构建 x64 portable + NSIS
6. 检查 `dist-electron/win-unpacked/resources/backend.exe`
7. 生成 `dist-electron/SHA256SUMS.txt`

## 模型与能力

模型目录由桌面应用设置为 Electron 用户数据目录下的 `models`。本版本不包含可信模型下载源，因此没有虚构自动下载 URL；需要真实模型下载和推理运行时的能力仍显示为不可用，并不会阻塞播放器基本功能。

## 卸载与数据

NSIS 使用单用户安装，卸载不会主动删除用户数据目录。模型和本地设置需要用户自行清理。

## 验证限制

Linux/macOS 开发环境不能替代 Windows x64 的 PyInstaller、portable、NSIS 和安装/卸载 GUI 验证。Windows 产物需要在 Windows 主机或 GitHub Actions Windows runner 上完成最终验证。
