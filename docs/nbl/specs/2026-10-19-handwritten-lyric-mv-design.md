# 「温光浮字」手书歌词 MV 重做设计（AE 手书方向）

> 状态：v4 构图与动效精修已实施并通过浏览器及静态验证（2026-10-20）；下文 v2/v3 作为历史设计记录保留，最新行为与证据见下方 v4。范围：只重做可视化效果 `cinematicLyricDrift`（显示名仍是「温光浮字」），
> 不改 Home / Player / 全屏歌词等 V7 核心视图，不改歌曲与歌词存储格式，不改效果 ID 和设置字段。

## v4：2026-10-20 构图与动效精修

本轮针对真实浏览器画面中「歌词像字幕、留白失去重心、纸面偏黄、线稿粗糙、动画持续抖动」的问题实施调整。用户指定 GPT-6 Luna Max 子代理完成；构图/时序和纸墨/线稿由两位代理分文件负责，第三位代理独立检查，主代理负责实际画面、原生媒体行为和集成验证。

- 横屏使用三种受控构图，歌词与一幅较大的速写组成主次关系；竖屏使用上方速写、下方宽字区。减少角落贴纸与标注，不靠增加粒子填满留白。
- 长句在安全宽度内平衡换行，优先空格、标点和可用的中英文词边界；保持字素及原 LRC 单元时间。超长输入使用有界成本的无损回退，避免排版阻塞绘制线程。
- 强调字先保留放大后的布局宽度再定位；译文按主句实际底边排版。长句进入间奏时保留多行余韵，纯器乐使用歌曲元信息与居中速写，不生成伪歌词。
- 默认纸面改为中性浅纸，降低折痕、杂点、暗角和大面积黄色光。植物轮廓使用平滑、收尖的笔触；完成后的插画保持稳定，落笔期间才有轻微手绘变化。
- 运镜由绝对音乐时间控制；换页具有可见的离场、抬页和入场阶段，并连续衔接镜头。转场快照、译文选择和缓存失效使用明确的镜头边界。
- 减少动态效果时使用单个完整页面，歌词起点直接可读；不让暂停在镜头起点或转场中点产生空白。
- 纸面、墨迹与路径缓存具有一致的输入身份和内存预算。高分辨率静态纸层允许降低离屏采样密度；歌词主画布仍按实际视口绘制。
- 沉浸式可视化隐藏全局悬浮播放器和 AI 笔记，离开后恢复；悬浮播放器保持挂载以保留原有快捷键，全局音频所有者不重挂，资料管理路由保留自己的播放条。

书写效果仍是按歌词时序揭示字体轮廓，不具备汉字真实笔顺数据。固定音乐时刻的图像复现使用相同字体、视口、参数和零频谱输入验证；实时音频的频谱平滑历史、系统字体和实际设备性能不在该图像一致性结论之内。验证结果与本地证据位置记录在 [本轮实施计划](../plans/2026-10-20-handwritten-mv-editorial-refinement.md)。

## 1. 为什么重做

旧实现是「暗场舞台 + 顶部灯轨 + 透视地网 + 居中双行字幕」：文字被画在背景上，而不是属于画面。
继续调色或加粒子不会改变这种「通用舞台底图」的观感。用户要求的是 AE 制作的手书 MV 质感：
手写字被一笔一笔写出来，纸面有材质和光，页边有涂鸦和标注，镜头和转场有导演感。

## 2. 新的视觉语言

一首歌 = 一叠被暖光照亮的手写歌词纸。每个镜头是一页纸，页脚有编号，页眉写着曲名与艺人。

| 图层     | 内容                                                                                    | 目的                                       |
| -------- | --------------------------------------------------------------------------------------- | ------------------------------------------ |
| 光场     | 桌面、纸页投影、撕纸边、阳光光斑、斜向窗光、浮尘、胶片颗粒、暗角                        | 让纸「存在」于空间中，而不是一张满屏底图   |
| 纸张     | 纸纤维、杂点、晕染、茶渍、折痕、边缘内侧压暗                                            | 静态材质感；只按调色板与视口缓存一次       |
| 页边涂鸦 | 手绘心形 / 星 / 云 / 音符 / 麦穗 / 月牙 / 波纹 / 光线等，按镜头 seed 稳定选取与落笔     | 手账感；涂鸦和歌词发生关系，而不是随机撒点 |
| 插画     | 每个 profile 一张大幅铅笔线稿（麦穗、月牙、窗光、涟漪、光线），画在文字相反一侧         | 给留白一侧主体，避免整页只有一行字         |
| 歌词     | 铅笔辅助线 + 墨迹逐字书写 + 笔尖湿墨/飞溅 + 干笔重影 + 重点词标注（下划线/圈画/荧光笔） | 手书 MV 的核心                             |
| 文字氛围 | 主句后一层淡淡水彩、当前句字缘暖光                                                      | 让字从纸上「浮」起来，呼应「温光浮字」     |
| 页饰     | 顶部和纸胶带、页眉小字、页脚页码、片尾红印章                                            | 编辑感与仪式感                             |

### 2.1 歌词行为

- 主句字号最大、位于镜头锚点；前一句缩小并褪成浅墨，后一句只保留铅笔稿。
- 短中文句（≤8 个字符、以中日韩文字为主）竖排成一列；竖排时只保留主句，字号按列高反推，保证不被裁切。
- 逐字进度沿用既有 LRC 估算单元（`estimateLineUnits`），全部由绝对音乐时间推导：
  暂停、seek、倍速、重绘得到同一帧。
- 重点标注覆盖 2–3 个连续单元，在整段写完后 0.16s 落笔，可选下划线 / 圈画 / 荧光笔；
  颜色在暖金与朱红之间按 seed 稳定选择，主句墨色密度也在 3 档间稳定变化。
- 间奏与器乐镜头不伪造歌词：保留上一句淡墨「余韵」、插画与涂鸦；片尾是手写曲名 + 艺人 + 专辑 + 红印章，
  片尾排版有「署名 / 明信片 / 竖排落款」三种变体。
- 长句排版避免「最后一行只剩一个字」的孤字：只超出一点点时并回一行；
  页面版式有居中 / 左三分 / 右三分 / 偏低 / 偏高 / 阶梯 / 斜向 / 明信片 / 页边批注等变体，由 seed 稳定决定。
- 无歌曲 / 无歌词时显示一页带涂鸦与胶带的空纸，有阳光与浮尘，不显示伪歌词。

### 2.2 镜头与转场

- 每个镜头缓慢推近（约 1.006 → 1.02–1.05），叠加**两层 value noise** 的手持漂移
  （不再用正弦叠加，避免可察觉的循环感；镜头内持续缓动，不在末段停死）。
- 纸面与内容分层视差：内容层使用 1.16× 的漂移/旋转，纸面保持 1.0×，让字像浮在纸上。
- 换页用转场快照做交叉溶解 + 暖光扫过（按既有 transition kind 决定强度），不闪黑、不硬切；
  `focus-pull` / `flare-cut` / `lights-out` 三种 kind 有可辨识的差异。
- `prefers-reduced-motion`：关闭运镜、粒子漂移与涂鸦落笔动画，文字直接显示，保留静态光场与清晰歌词。

### 2.3 动画手感（v2 精修）

- **书写**：逐字遮罩带斜向湿润边缘；字与字之间加入确定性的 8–45ms 抬笔间隙；
  写完 0.2s 内做一次轻微沉降（scale 1.012→1、墨色由湿转干）；笔尖湿墨/飞溅只出现在正在写的字上。
  铅笔辅助稿只在未写到的部分淡淡保留，已写的字不再叠一层「幽灵重影」。
- **涂鸦**：每笔 easeOutCubic 生长、笔与笔错开 0–45% 进度；落笔期间每 100ms 换一组手抖点
  （boiling line，时钟由音乐时间派生，seek 后可复现）；画完走缓存的 `Path2D` 快路径。
- **标注**：下划线/圈画带 easeOutBack 回弹与压力变化；荧光笔是一整道带边缘起伏的水彩带，
  末端有笔触拖尾，而不是两条均匀色块。
- **页眉/页码/页饰**：每镜头 0.45s 淡入、切页前 0.6s 淡出；胶带/回形针/邮票/折角/小印章按镜头
  seed 变化，在镜头开始后 0.25–0.55s 逐个「贴」上去，印章在句子写完后盖下。

### 2.4 性能与画质

- **静态层烘焙**：暗角 + 四边压暗 + 桌面边缘按（尺寸、调色板、暗角强度）烘焙成屏幕空间缓存，
  每帧只 `drawImage` 一次。
- **半分辨率光层**：阳光、光核、横向光条、窗光、背光画到约 0.44–0.5 倍尺寸的离屏画布，
  每 90–260ms 重画一次；每帧用 `screen`/`multiply` 各贴一次。
- **无 `shadowBlur`**：字缘暖光改为低透明度暖色重描。
- **路径缓存**：涂鸦/插画的抖动点列与 `Path2D` 按（spec 对象、unit 尺寸）缓存；
  落笔阶段复用点列做局部描边，画完直接描整条 `Path2D`。
- **文本缓存**：页眉、页码、译文、署名按（文本+字号+字体）缓存测量结果，不再逐帧 `measureText`。
- **转场快照**：转场期间把 outgoing 内容抓成一张离屏画布，之后只画「纸 + 快照淡出 + incoming 淡入」；
  快照记录抓取时的音乐时间，seek 后偏差超过 0.12s 就重抓，保证 seek 后画面正确。
- **画质档位（确定性）**：由画布像素量静态决定，而不是绘制耗时——
  1920×1080 为 0 档，1080p@dpr2 为 1 档，4K 级为 2 档；同分辨率下每次播放细节一致。
  另保留「持续多帧 >22ms 才升一档」的紧急降级，且绝不自动降回，避免细节来回跳。
- 仍为纯 Canvas 2D、无新依赖；不使用 `ctx.filter`、不再使用 `shadowBlur`。

## 4. 技术边界

- 纯 Canvas 2D，不引入新依赖；入口仍是 `drawCinematicLyricDrift(effectCtx)`。
- 复用：`lyricTimeline`（LRC 解析与逐字时间）、`lyricPlaybackClock`（播放时钟与 seek 判定）、
  `lyricFilmProgram`（镜头编排）、`lyricFilmLyrics`（行角色与译文匹配）、`lyricFilmComposition`
  （标题揭字与竖排字素切分）。
- 新增：`handwrittenPalette`（调色与字体）、`handwrittenScene`（分镜底稿，纯函数）、
  `handwrittenPaper`（纸面、光、尘、颗粒，纹理缓存）、`handwrittenDoodles`（笔触、涂鸦、标注、印章）、
  `handwrittenInk`（手写墨迹渲染）。
- `lyricFilmStage` 不再参与渲染，但其单测与类型仍保留；不删除不确定代码。
- 性能：纸面纹理按调色板 + 视口缓存，屏幕覆盖层按（尺寸、调色板、暗角）烘焙，
  光层半分辨率 + 限帧更新；每帧主要成本是少量 `drawImage` 合成与正在书写的字。
- 确定性：所有动画时钟（镜头噪声、涂鸦 boiling line、灰尘、光层、颗粒）都从绝对音乐时间派生；
  画质档位由画布像素量静态决定；转场快照记录抓取时间并在 seek 偏差 >0.12s 时重抓。
  暂停、seek、倍速、重绘在同一音乐时刻得到同一帧（像素级一致）。

## 5. 验收

1. 静态截图能看出「纸、光、手写、涂鸦、标注」共同构图，不再是暗场舞台 + 字幕。
2. 同一音乐时刻重绘 / seek 前后镜头、字形进度一致；暂停冻结；像素级确定性已验证。
3. 竖排、移动端窄屏、超宽屏均不裁切主句；无歌曲、无歌词、间奏、片尾都有对应画面。
4. 设置面板中的字体与配色名称与新语义一致。
5. 性能：1080p 下 JS 绘制提交时间约 1.2–1.5ms；转场不再双绘；弱机/高分屏由确定性画质档位兜底。

## 6. v3 手书美学深化（2026-10-20）

针对「现在不是很美观」，按真实手书/手账的视觉语言重做材质、字形、页面构成与转场（研究依据：
handwriting-research.md（本地调研文档，原文在 gitignore 的 scratch/viz/ 下，未随仓库保留），计划：
[2026-10-20-handwritten-aesthetic-deepening.md](../plans/2026-10-20-handwritten-aesthetic-deepening.md)）。

### 6.1 纸与色

- 纸底改中性浅色（L\* 90–94、chroma ≤0.03），不再用整页米黄 + 棕色暗角；
- 纸纹按 `width×dpr` 烘焙；两处 ≤5% 面积的低透明度水彩斑；暗角改纸边线性压暗（总强度 ≤0.18，过渡 ≥40px）；
- 光斑由「完美圆 + 正弦呼吸」改为椭圆 + 偏移第二光斑的慢漂移。

### 6.2 字

- 字形 sprite 图集：每字只烘焙一次，内含渗墨、墨积、干笔飞白、三叠印笔压；每帧只 `drawImage`；
- 逐字字号/基线/旋转/透明度抖动，advance 抖动 ±5%，标点后额外空隙；
- 铅笔稿是独立、变形、更淡的草稿层（≤0.12α），不再是同字体低透明度复制；
- 关键词放大 1.25× 作为视觉落点；旧句缩小到 0.34×、α≤0.26。

### 6.3 页面构成

- 单页 ≤2 件实物 + 2–3 个涂鸦；第一笔涂鸦贴着文字块形成焦点簇；
- 新增撕纸片、拍立得、页边小字（日期/批注/符号）；胶带必须压住内容或纸边，带撕口/纤维/投影；
- 印章缺墨 15–30%；邮票内容改为手写小字 + 邮戳，不再用通用图标语言。

### 6.4 转场

- 去掉同位置双字 crossfade：0–45% 旧页退场，45–55% 只留纸与暖光，55–100% 新页入场；
- 暖光泄漏强度减半；past 行不再大字号压层。

### 6.5 工程约束

- 字形/纸纹缓存均按（字符/尺寸/字体/颜色/样式/DPR）确定；同一音乐时刻像素级一致；
- 1080p draw med 约 1.5ms、dpr4 压力场景 0 丢帧；effects 119 tests 全绿。
