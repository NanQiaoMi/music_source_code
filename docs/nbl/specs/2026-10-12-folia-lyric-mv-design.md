# 「温光浮字」Folia 绘光式歌词 MV 重做规格

> 状态：实施基线，2026-10-12
>
> 范围：在现有可视化中完整重做「温光浮字」一个效果，使它呈现 Folia 绘光式程序化歌词 MV。
>
> 依据：Folia v0.7.18，上游提交 36c28862fc9bc69546528524b2f687e5d8c2e9e5。

## 1. 目标与取舍

目标不是给歌词增加几种动画，而是让整首歌像一支由灯光、构图、镜头和歌词共同编排的 MV：播放开始先建立舞台，歌词按段落进入不同镜头，纯音乐段落有独立画面，段落边界通过灯光和焦点完成转场，最后以片尾卡收束。

Folia 的 Partita「云阶」、Fume「浮名」和 Lumiere「绘光」是独立模式。Folia 把 Lumiere 明确描述为舞台光歌词导演，并在中文界面称其为舞台光 PV 可视化。因此本次只迁移 Lumiere 的整体导演机制，不混入另外两个模式的版式或相机逻辑。参考入口、编排器及场景说明：

- [Lumiere 模式入口](https://github.com/chthollyphile/folia-major/blob/36c28862fc9bc69546528524b2f687e5d8c2e9e5/src/components/visualizer/lumiere/entry.tsx)
- [全曲段落/镜头编译](https://github.com/chthollyphile/folia-major/blob/36c28862fc9bc69546528524b2f687e5d8c2e9e5/src/components/visualizer/lumiere/lumiereProgram.ts)
- [镜头切块规则](https://github.com/chthollyphile/folia-major/blob/36c28862fc9bc69546528524b2f687e5d8c2e9e5/src/components/visualizer/lumiere/program.ts)
- [歌词窗口构图](https://github.com/chthollyphile/folia-major/blob/36c28862fc9bc69546528524b2f687e5d8c2e9e5/src/components/visualizer/lumiere/text/lyricWindow.ts)
- [舞台场景图层](https://github.com/chthollyphile/folia-major/blob/36c28862fc9bc69546528524b2f687e5d8c2e9e5/src/components/visualizer/lumiere/scene.ts)
- [灯光转场](https://github.com/chthollyphile/folia-major/blob/36c28862fc9bc69546528524b2f687e5d8c2e9e5/src/components/visualizer/lumiere/lumiereTransitions.ts)

旧的「云阶排字 + 浮名文字场 + 绘光光束」融合规格已被取代。它只画中心歌词、前后歌词和装饰光束，没有全曲分镜，不能作为新实现的验收标准。

## 2. 产品范围与兼容边界

- 只重做现有效果 ID cinematicLyricDrift，显示名仍为「温光浮字」。
- 保持正式 Canvas 2D 可视化入口及现有效果设置字段；已有用户保存的数值继续有效，不新增必需迁移的持久化字段。
- 不复制 Folia 代码，不引入 Pixi、视频片段或新的渲染依赖；用项目现有 Canvas 2D 实现程序化舞台画面。
- 不修改 Home、Player、全屏歌词核心、播放队列、歌词服务、歌曲数据格式、localStorage 或 IndexedDB。
- 沿用已确认的同步策略：当前歌曲只有 LRC 行级时间时，按行时间区间估算字素/短词组显影节奏。该节奏用于视觉表现，不标称真实词级同步。
- 音频频谱只轻微调制光强、雾和微尘；它不推断歌词段落或真实节拍点。

## 3. MV 播放流程

### 3.1 先编译整首歌

从完整 LRC 行时间和歌曲时长确定一个可随机访问的歌词电影程序。每个镜头、灯位、构图和转场由歌曲 ID 与镜头序号稳定派生。同一首歌在播放、暂停、跳转、回退和重绘后始终落在同一个镜头和构图，不依赖只向前累积的动画状态。

- 开头时间较长时先播放无字前奏镜头。
- 普通镜头以一至两条 LRC 行为主体，时长尽量不超过约 7 秒；长行独立成镜头。
- 行后有明显空档时插入器乐/间奏镜头，让画面继续演出而不是停住最后一句。
- 连续歌词按可观察的间隔与行数切成段落；现有数据没有歌曲段落标签，因此这些边界是时间线启发式结果，不声称语义上准确识别主歌或副歌。
- 结尾在最后一句歌词之后过渡到片尾卡，曲名、艺人和专辑信息仅作为片尾文字，不伪装成歌词。

### 3.2 每个镜头都是一组舞台设计

镜头使用稳定选择的灯光方案，包括追光、棱镜折射、窗隙光、焦散水纹、植物线稿、星象和浮尘等类别。它们由渐变光束、线稿、几何舞台、薄雾、远近尘点及散景构成；类别随段落和间奏变化，避免一首歌反复使用同一灯位。

歌词不是全曲文字墙。画面保留当前句为视觉主角，并在它周围安排少量将唱/唱过的句子。当前字素按估算时间逐个进入暖色高光，未唱文字在灯束穿过时呈冷色微光，唱过的字留下短暂光痕并退入雾中。行切换时文字换位，镜头随焦点缓慢推近、拉远或横移。

### 3.3 段落转场与无歌词状态

段落边界使用熄灯、闪光或拉焦；转场按歌曲种子选择且连续两次不重复，持续约 0.35–1.1 秒，使用交叉淡化、轻微缩放或模糊，不出现生硬全屏硬切。镜头内的灯束交叉淡入淡出，运镜在边界放慢后重新起步。

无歌词、纯音乐或歌词尚未加载时，播放灯光、舞台线稿、雾与尘点构成的器乐镜头，不用标题拆字，也不把曲名当作歌词。未选择歌曲时保持静止或低幅呼吸的空舞台。

## 4. 播放、布局与无障碍要求

- 暂停时歌词时钟停在当前字和镜头；舞台仅保留低幅环境运动。恢复后继续同步。
- 倍速通过现有播放时钟推进；seek、回退、切歌和迟到歌词会按目标音乐时间重算分镜。
- 视口变化重新测量文字与构图；任何歌词不得裁切到画布外，极窄宽高比自动减行或缩字号。
- prefers-reduced-motion 下停止连续运镜、粒子漂移和强光闪烁；保留清晰的当前句与即时镜头变化。
- 固定并限制粒子/绘制图层数量；不在每帧创建大型离屏缓存，不让频谱变化造成整屏闪动。
- 保留原有字体、调色板、字号、辉光、速度、颗粒和暗角设置字段；仅调整设置文案，使其对应新的舞台效果。

## 5. 完成验收

1. 与旧版相比，画面明确出现连续的 MV 镜头序列：前奏、歌词镜头、间奏、不同舞台灯位、段落转场和片尾卡。
2. 相同歌词时间线和种子生成稳定镜头；同刻多行仍作为独立排版数据，不合并成斜杠句。
3. 段落中每个镜头只含有限歌词行；长行独立，明显间隔有可见器乐镜头。
4. 行级 LRC 估算显影覆盖完整文本且不越出歌词行区间；暂停、倍速、seek、回退和切歌后画面正确重算。
5. 无歌词时只有器乐舞台，无伪歌词；片尾元数据只在歌词结束后出现。
6. 常规与窄屏下文字完整可读；减少动态效果设置下没有持续运镜和强闪光。
7. 聚焦测试、受影响文件 lint、TypeScript、生产构建和本地实际播放画面均记录实际结果。若没有可播放音源，必须明确记为未执行，不能把截图或静态构建当作同步验证。

## 6. 非目标与已知限制

本次不是对 Folia 所有模式的全量复制，也不会移植其播放器和 Pixi 场景系统。MIMI 当前没有真实字级时间、歌词人声轨、主歌/副歌标签或镜头标记；分字节奏和段落分类是确定性视觉估算。舞台美术由 Canvas 程序化绘制，不是逐像素复刻，也不嵌入参考视频。

## 7. 首轮实现后的保真修正（2026-10-12）

用户复核首轮“整曲分镜 + 舞台层”后指出画面仍未达到 Folia 的 MV 制作感，因此首轮实现不作为视觉验收通过。本次跟进保留上面的 Lumiere 导演机制基线，并具体加强这些画面行为：

- 每个歌词镜头只显示局部歌词窗口，当前句成为主视觉，相邻句以退后层次陪衬；按镜头 profile/种子改变主句位置，并让镜头从稳定方向入场。
- 短 CJK 句有小概率采用受安全区约束的竖排；快速歌词中共享时间戳的多字单元拆成单字槽，长句与拉丁文本保持横排。字素使用绝对音乐时间产生稳定入场轨迹、暖色点亮与短余光，舞台光线按字素位置采样。
- 相邻同类镜头用短焦点拉移平滑衔接；灯灭/闪光等大转场只用于不同场景类型。暂停时歌词与镜头停住，雾、灯、尘点以低幅度继续呼吸。
- 可用翻译 LRC 时，只显示与当前源歌词时间近邻对齐的译文；缺行或偏差超出相邻行窗口时隐藏字幕，且翻译时间组在切歌或译文变更时缓存重建。结束部分先保留器乐舞台，再由曲名逐字显影，随后显示艺人/专辑。
- 舞台灯位、场景轮廓、前中后景与局部照度采样由同一确定性灯光 rig 驱动；同一歌曲时间经 seek 或重绘仍得到稳定镜头与构图。

这些调整仍是资产免依赖的 Canvas 2D 程序化绘景，目标是学习 Folia Lumiere 的镜头组织、灯位和歌词表现机制，不宣称逐像素复制 Folia 的画面。分字时序仍由 LRC 行间隔估算，不是真实词级同步。静态测试与构建通过不构成动态播放证据；真实歌词、暂停、倍速、seek 和片尾画面需要单独在不改变用户播放会话的播放器中观察。
