# Folia 启发的「温光浮字」歌词视觉迁移设计

> 状态：历史规格，已被 2026-10-12《Folia 绘光式歌词 MV 重做规格》取代。旧实现虽按当时规格完成，但用户反馈其画面不符合 Folia；不得继续作为本次实施基线。
>
> 日期：2026-10-11
>
> 范围：可视化视图中的「温光浮字」Canvas 效果及其效果设置。实现保留 LRC 行级时间戳，并在行区间内估算字素进度。

> **后续更正**：本文件曾将 Partita、Fume、Lumiere 三个独立模式融合为单一画面，这不是 Folia 的实际构成。请以 [2026-10-12 重做规格](./2026-10-12-folia-lyric-mv-design.md) 和对应实施计划为准。

## 1. 目标

把当前「居中整句 + 横向流光」的歌词画面，迁移成一套具有 Folia 歌词视觉特征的统一舞台：歌词层级更丰富，当前唱到的词/字更明确，背景光与文字运动彼此呼应，同时保持现有播放器架构、歌词存储和设置兼容。

目标结果：

1. 当前句仍是清楚的阅读焦点，但不再固定为一条居中的完整横排。
2. 当前句被编排为稳定、错落的短行/词组；活动字素按播放时间逐步提亮，已唱文字留短暂余辉，未唱文字保持柔和。
3. 前后歌词形成低对比度、有远近层次的文字场；暖色光束、字缘光晕和少量微尘围绕当前歌词，整体看起来像同一个视觉效果。
4. 暂停、拖动进度、回退、切歌、歌词延迟到达、没有歌词、窗口缩放及后台切换时，画面状态都能稳定恢复。
5. 不改变 Home、Player 或全屏歌词核心视图，不改变歌曲持久化字段，不新增渲染依赖。

## 2. 用户已确认的设计决定

- 参考 Folia 的歌词呈现，不只学习单个细节；已研究「云阶（Partita）」「浮名（Fume）」和「绘光（Lumiere）」三种构图。
- 温光浮字采用完整的 Folia 风格迁移，不保留原来的单句横排作为主要构图。
- 三种参考风格融合成一个连续、统一的效果，不做三个独立样式切换。
- 当前应用只提供歌词原文和 LRC 行时间；词/字节奏按行时长估算，作为视觉节奏，不宣称是真实词级时间同步。
- 无歌词、纯音乐或歌词尚未加载时，学习 Folia 的空歌词氛围处理：保留环境光场，显示曲名/艺人名和少量呼吸星点；不把曲名拆成伪歌词。
- 保留当前 Canvas 2D 渲染管线和温光浮字效果 ID；Folia 的代码仅作为行为与视觉研究材料，按 MIMI 结构独立实现。

## 3. 当前实现与 Folia 参考研究

### 3.1 当前「温光浮字」

现有效果入口在 `src/components/visualization/VisualizationView.tsx`，渲染函数在 `src/components/visualization/effects/cinematicLyricDrift.ts`。效果由 `requestAnimationFrame` 驱动画布，读 `audioStore` / `playerStore` 的歌曲、歌词、时间与播放状态。

当前构图由以下部分组成：

- 一句当前歌词在画布中心水平居中，上一句在上方淡出。
- 整句先以低亮度绘制，再通过单条横向渐变扫光模拟演唱进度。
- 歌词只解析 LRC 行时间；活动句内部进度根据字符数和下一行时间估算。
- 背景使用径向暗场、四个流动色斑、胶片颗粒与暗角；低频轻推色斑亮度。
- 文字的进出场、进度和音频包络已使用帧率无关的平滑系数；噪点纹理预生成并按 Canvas context 缓存。

画面设置在 `src/components/visualization/VisualizationSettingsPanel.tsx`，默认值在 `src/store/visualizationStore.ts`：字体风格、调色板、歌词字号、流光羽化、背景流体速度、弥散光晕、胶片颗粒和暗角。

源码审查还发现五个需要在实施中修正的时序/生命周期缺口：当前行只在 `isPlaying` 为真时选择，暂停可能把歌词清空；store 时间之间的插值按 1× 速度推进，没有应用 `playbackRate`；行间隔被强制设为至少 1.2 秒，短间隔里的估算进度会显得过慢，切到下一句时可能尚未完成；若切换到歌词文本相同的另一首歌，仅比较原始歌词字符串不会使旧动画缓存失效；歌词解析、当前行、淡入进度等状态目前保存在模块级变量中，效果切换或不同画布实例可能继承陈旧状态。重构时需把歌曲 ID、播放时间、播放状态和播放倍率纳入状态解析，并为动画状态定义实例生命周期，而不是继续沿用这些隐含状态。

当前解析器只识别 `[mm:ss]` / `[mm:ss.xx]` 行时间；`[offset:]` 不参与偏移计算，纯文本歌词不会生成可播放行。规格继续保留这条数据边界：没有可解析行时间时进入曲目信息与环境光场状态，不临时猜测逐行时钟。

本次观察到的浏览器画面停在 0:00 且播放器暂停，歌词尚未进入；静态画面显示暗色蓝紫氛围与悬浮播放器。动态进度判断来自源码时序逻辑，不把这张静止截图当作动态运行证据。

### 3.2 Folia 参考形式

已克隆的 Folia 源码在 `D:/26project/folia-major`；本设计依据本地工作副本 `main` 的 `b298338`，而非直接依赖或复制其中的实现。

- **云阶 / Partita**：以当前歌词行的计时词为基础，先处理 CJK 语义分组和标点粘滞，再将词组编排成行数不均匀的错落短行。每一行有稳定的位置和轻微偏移，活动词发光，等待词和唱过的词采用较低亮度。可见结果像一页有节奏的乐谱，而不是随机散字。
- **浮名 / Fume**：把歌词编成连续文字场；当前句受到镜头聚焦，前后句作为已经读过或尚未读到的文字留在空间中，形成远近和阅读轨迹。参考截图见 `D:/26project/folia-major/img/preview-fume.png`。
- **绘光 / Lumiere**：以逐字字形、光束、雾、光晕和微尘构成舞台。字是否发亮与光场和字素时刻相关，切镜头时光线、歌词和点光一同过渡。参考截图见 `D:/26project/folia-major/img/preview-lumi.png`。

动画源码进一步显示了三种节奏语言：Partita 用 waiting / active / passed 三态保持短行位置稳定；常规整行约从 0.9 倍缩放、10px 虚焦进入，约 0.3 秒退场；活动词使用 stiffness 200 / damping 20 的弹性回位，唱过后的旋转约 5 秒才缓慢收敛。Fume 的逐句追焦通常约 0.055–0.13 秒，按状态限制在 0.03–0.30 秒，概览镜头约 0.38–0.58 秒，另有 5.8–8.5 秒的大周期轻浮动；Lumiere 的歌词窗口提前约 1.2 秒开始换位，整段滑动约 1.5 秒并对不同行错开起步，逐字点亮至少约 0.3 秒，闪点约 0.15 秒起亮、约 0.45 秒衰减。其微尘按稳定种子和时间直接求位置，进入光束时才明显发亮。可参考的实现位置包括 Folia 的 `src/components/visualizer/glowWordTiming.ts`、`glowWordVariants.ts`、`fume/fumeCameraStep.ts`、`fume/fumeCamera.ts`、`lumiere/text/windowTiming.ts`、`lumiere/text/lyricWindow.ts` 与 `lumiere/light/motes.ts`。

实现中吸收的是这三种形式的设计规律：稳定的错落布局、低对比歌词纵深、光照驱动的局部字光。MIMI 不迁移 Folia 的 React/Framer Motion/Pixi 运行时，也不照搬其内部源码。

### 3.3 三种实现方案比较

| 方案                       | 主要构图                                                           | 优点                                                    | 代价                                                                 |
| -------------------------- | ------------------------------------------------------------------ | ------------------------------------------------------- | -------------------------------------------------------------------- |
| 云阶主导的统一光场（选定） | 错落短行与逐字点亮为主体，少量前后句作远景，暖光与微尘提供舞台氛围 | 三种参考特征清楚但不相互抢焦；延续 Canvas 2D 和现有设置 | 需要新建布局与逐字时钟；必须限制背景文字密度                         |
| 浮名主导的文字漫游         | 整首歌词形成连续空间文字场，镜头围绕当前句移动                     | 沉浸感和歌词纵深最强                                    | 当前句的快速识别可能变弱；整首歌词排版、镜头轨迹和长文本处理范围较大 |
| 绘光主导的逐字舞台         | 横向/轻倾斜歌词配字形光晕、移动光束和粒子                          | 局部光照与逐字表演最突出                                | 云阶式短行结构变弱；若迁移 Pixi 会新增渲染栈和资源生命周期复杂度     |

采用第一种方案；后两种仅提供设计细节，不另做可切换模式。

## 4. 视觉构图与图层

由后向前分成五层：

1. **暗场与色斑**：保留温光浮字的径向暗场、既有色板、缓慢流体色斑和暗角。背景不得压过当前歌词，也不叠加第二套大面积色云。
2. **歌词远景**：当前句前后各取有限数量的有效歌词行，放在较远的视觉层。远景低亮、低透明、轻微虚化或缩小；歌词缺失时不构造空白文字。
3. **光场**：在当前词附近绘制一到两束低亮度暖光/柔光带，缓慢横扫或改变角度。低频只轻推整体光强，高频只提供少量细微闪烁，不让整屏跟随频谱跳动。
4. **当前句布局**：将当前句拆为 2–5 个短行/词组，依据字数与画布比例确定行数；行间有轻微左右错位和垂直节奏。布局对同一句保持稳定，不逐帧随机重排。
5. **字素高亮与尘光**：当前时间前的字保持柔和底色，唱到的字增加亮度、暖色字缘光晕和短暂余辉，过去的字逐渐退回低亮度。少量微尘仅在光束附近显现。

视觉优先级必须保持为：当前歌词 > 近景歌词轨迹 > 光束/字光 > 背景色斑与装饰。装饰元素不能形成大量可读性相近的文本块。

### 4.1 布局规则

- 中文、日文等 CJK 文本优先按字素形成布局单元，常见后置标点随前一单元移动；避免标点落在单独一行或远离词组。
- 拉丁文本优先按空格分组；标点和缩写后缀附着相邻词组。若一个词组过长，按字素拆分而不裁切文本。
- 短句使用较少行数、较大的字；长句增加短行数量并有限缩字号，使所有字保持在安全区域内。
- 错落只改变每个词组所在行的位置，不改变原文阅读顺序；横排按从上到下、每行从左到右推进，不能为追求随机感而重排歌词。
- 每行的偏移由歌词行时间、行号和文本长度的稳定种子派生。相同歌词在 seek、回退和重渲染后保持一致。
- 布局和 Canvas 绘制使用同一套测量数据，包含字体、字号、DPR、容器尺寸和词组间距；设置改变或容器 resize 时重新测量。
- 颜色继续以当前温光调色板为主，活动字使用经亮度钳制的暖色高亮；不新增未经确认的专辑封面取色链路。

### 4.2 文本状态和转场

每个布局单元有三个可由播放时间确定的状态：

| 状态     | 呈现                                                              |
| -------- | ----------------------------------------------------------------- |
| 未唱到   | 低亮文本，保留位置和可读轮廓；不提前强发光                        |
| 正在点亮 | 颜色和局部柔辉缓升，必要时短暂出现小型星点；字号/位置只做轻微变化 |
| 唱过     | 保留短余辉后逐渐降为远景文字或淡出，不瞬间消失                    |

行切换时，新句从轻微纵深/透明度偏移进入，旧句沉入远景；交叉淡化与逐字点亮相互独立，避免长句结束时进度扫光跳变。暂停时显示保留在暂停时刻；seek 后立即按目标时间重算，反向 seek 不沿用旧的动画累计状态。

### 4.3 动画节奏与曲线

动画分成两套时钟：歌词排布、字素进度、自然行切换由歌曲播放时间驱动；色斑呼吸、环境光摆动和微尘漂移由单调环境时钟驱动。当前 `EffectContext.musicTime` 是播放器时间快照，`EffectContext.time` 是 RAF 时间戳；两者构成唯一的歌词校时输入，避免渲染器再开一套彼此漂移的 `performance.now()` 时钟。Canvas 每帧只读取和绘制状态，不用每帧累加歌词位置；相同歌曲时间必须得到相同歌词状态，使暂停、拖动和反向播放都能从时间轴重建。下列数值是本效果的首轮调校目标，不是对 Folia 参数的逐项照搬。

| 动作阶段       | 首轮目标                                                     | 曲线与视觉规则                                                                                                                                                       |
| -------------- | ------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 下一句预备     | 行开始前约 0.25–0.40 秒                                      | 只显出很淡的行形/远景轮廓，透明度不超过主句的 15%；不点亮字、不移动当前主句。布局在此时预先测量。                                                                    |
| 当前句入场     | 常规句约 0.24–0.36 秒；很短的句按可用间隔缩至约 0.06–0.16 秒 | `easeOutCubic` 或同等柔和的 ease-out；由透明度 0、缩放 0.97、纵向偏移约 1.2% 画布高度、仅行组短暂使用不超过 2px 的轻虚焦进入稳定位置。极短行不做夸张弹簧或逐字模糊。 |
| 字素点亮       | 按估算出的字素开始/结束时间推进；最短有效点亮约 0.08 秒      | 约 0.15–0.30 秒内升至暖色；单字光晕先亮后收，点亮闪点约 0.12–0.18 秒起亮、约 0.35–0.55 秒衰减。主要亮度跟随歌词时钟，不由音频瞬态决定。                              |
| 唱过余辉       | 字素结束后约 0.35–0.60 秒保留近景余辉                        | 字色与光晕先柔和回落；随后随整句沉入远景，不在每个字上产生新的爆闪。一个词组最多出现一个小星点，中文逐字序列按节奏稀疏选点。                                         |
| 行间交接       | 常规句约 0.30–0.48 秒；极短间隔约 0.08–0.18 秒               | 新句淡入并轻微靠近；旧句向上/后方移动不超过画布高度的 2%，同步降亮并缩至约 0.96。保持短暂交叉，不让两句同时达到主句亮度。                                            |
| 旧句远景       | 行切换后约 1.2–2.5 秒内逐步退远                              | 降至主句透明度约 15–28%，缩小不超过 8%，轻微虚焦；最多保留前后各两句，最远一层不再连续移动。                                                                         |
| 环境呼吸       | 一个周期约 8–12 秒                                           | 色斑、主句整体只做不同相位的缓慢漂移；位置振幅不超过画布高度的 0.8%，缩放变化不超过 0.6%。应避免所有元素同相呼吸。                                                   |
| 主光束         | 一个缓慢扫动周期约 12–18 秒                                  | 一束暖色主光配至多一束更暗的补光；横向覆盖缓慢移动约画布宽度的 1–2%，照亮歌词附近时才增强字缘与尘点。不得周期性熄灭或频闪。                                          |
| 微尘           | 常态只让约 3–7 个点清晰可见；总对象上限 18 个                | 使用稳定种子，沿低速漂移加小幅涡动；只在光束/歌词附近提亮，透明度缓慢呼吸。尘点不能与字的高亮同步齐闪。                                                              |
| 无歌词曲目信息 | 元数据到达后约 0.35–0.55 秒淡入                              | 曲名/艺人以常规文本显示，保持居中或略偏下；只用 3–6 个低亮呼吸星点。歌词加载后，曲目信息淡出、歌词舞台淡入，不把标题拆字。                                           |

#### 动作优先级与相位

- 歌词字素点亮是唯一跟随旋律时间轴快速推进的动作；句子布局、远景、光束和背景呼吸使用更慢的频率，避免所有层同时“动起来”。
- 活动字本体保持清晰边缘，光晕峰值不得把笔画冲成白块。正在唱的字可轻微放大，缩放变化控制在 1–2%；不让字在每帧跳位置。
- 颜色变化与亮度变化错开：先出现字本体的暖色，再让局部光晕在短峰值后退去；远景歌词降低亮度/尺寸，不依赖重模糊维持层次。
- 低频只缓慢调节全局主光强度，振幅控制在基线约 ±8%；高频只在受限的少数尘点上作很小的亮度变化，禁止全屏频谱闪烁。
- 粒子与环境光的位置由 `(歌曲/曲目稳定种子, 环境时间)` 直接求值，不用帧间积分。切歌时重新播种；resize 只重算比例坐标，不改变相位或音乐进度。
- 视觉节奏不得快于 LRC 的有效边界。行间隔不足以完整播放入场/退场时，缩短淡化而不是延后歌词时钟；连续时间戳相同或倒退时按既有过滤/排序规则选定一个稳定状态。

#### 播放控制与动画复位

- **暂停**：歌曲时钟冻结，字素状态和当前行位置完全保留；环境光以正常速度约 25–35% 的幅度继续缓慢呼吸，音频响应归零。
- **小幅时间校正**：250ms 音频状态刷新之间，仅在播放状态下按 `audioStore.playbackRate` 缩放 `EffectContext.time` 的经过时间做有界插值（当前播放倍率范围为 0.5–2.0）；暂停时直接使用 `musicTime`，插值不得让字素超过当前行的结束边界。
- **seek / 时间跳变**：检测到时间不连续或方向反转后，直接按目标时间恢复当前行与字素状态，不补播中间行、不重放闪点。当前画面仅允许约 0.10–0.18 秒的轻柔重新聚焦。
- **自然换句**：只在相邻有效 LRC 行之间做短交叉淡化；下一句布局提前预计算，避免换句时停顿或突然重排。
- **切歌或歌词替换**：立即失效旧歌曲的歌词测量、行布局、字素时间和歌词绑定尘光；背景基础呼吸可连续接上，新曲目文字从干净状态淡入。
- **歌词晚到**：歌词在播放中途到达时，根据当前 `musicTime` 直接定位当前有效行，显示当下应有的字素状态；不从第一行重放，不让已过去的歌词逐句追赶。
- **暂停中 seek**：即使播放状态仍是暂停，只要 `musicTime` 改变，就按新位置重建字素与行状态；暂停仅冻结自然推进，不冻结用户的 seek 操作。
- **窗口隐藏/恢复**：隐藏时停止 RAF；恢复时以最新歌曲时钟首帧重建歌词状态，并清零单帧 `dt`，不能把隐藏时长累计成位移或光强跳变。
- **减少动态效果**：显式监听 `prefers-reduced-motion: reduce`，不能依赖只覆盖部分 DOM 范围的全局 CSS；保留逐字进度、短行结构和层级，关闭尘点漂移、光束扫动及环境摆动，歌词转场仍用低幅度、短时淡化。

## 5. 歌词数据与视觉时钟

### 5.1 数据边界

`src/types/song.ts` 中 `Song.lyrics` 是字符串。当前温光浮字解析 LRC 行时间，没有可供它直接读取的词级时间轴；应用也不为这一效果提供 Folia 的 `Line.words` 对象。因此本次不扩展歌词服务、不改变 `Song` 持久化字段、不提高 Zustand 时间写入频率。

### 5.2 时间估算

- 每条有效 LRC 行的起点使用原始时间戳；下一条严格晚于该起点的有效行是当前行的硬上界，不为短间隔补足 1.2 秒。连续歌词间隔按真实间隔缩短入/退场动画，不能推迟下一句或继续点亮上一句。
- 末句没有下一行时间戳时，使用 2–5 秒的受限视觉尾长（结合文字长度估算并封顶 5 秒）；音频时长可用时不得越过歌曲结束位置。歌词尾长是画面停留估算，不表示演唱结束时间。
- 行内时间先转换为权重再归一化到该行可用时长：CJK 字素各占一个基准权重；拉丁词按字素数缓慢增长并设上限；空格只占很小权重；逗号、顿号与句末标点增加相邻字素的停顿权重。所有字素起止都从同一个 `[行起点, 行上界]` 区间推导，标点停顿不能额外延长区间。
- 可用行时长不足 0.18 秒时，整行作为一个快速高亮组处理；0.18–0.45 秒时合并为少量节奏组并缩短转场，避免每个字争抢几十毫秒而连续闪烁。更长行再逐字估算；任何字素有效持续不低于约 0.08 秒的下限只能在行区间内重分配，不能把高亮延伸到下一行。
- 多个时间标签对应同一文本时，按各自起点展开；同一时刻出现重复相同文本时合并为一个动画项；同一时刻出现不同文本时组成并发歌词组，同组共享行起点并按源顺序稳定排版，不能由二分查找随机丢掉其中一行。
- 与现有效果一致的元数据过滤、时间排序和二分定位规则应保留；明确不解析或应用 `[offset:]`。空文本、格式错误、负时间、无效时间或没有可用时间边界时回退到曲目信息/环境态，不得异常绘制。
- 视觉钟由音频时间驱动。播放时使用现有效果的帧内平滑策略填补 250ms store 更新间隔；暂停停止插值；seek/回退/换歌时清空过渡缓存后从目标时刻重建。
- 快速连句、极短行、末句、相同时间戳、LRC offset 元数据、长标点串和中英混排都要有有界回退行为。估算节奏不能跑过下一有效歌词行。

#### 时间轴示例

假设两条歌词为 `[00:12.00]晚风吹过你，` 与 `[00:14.80]我仍旧留在原地`。第一句的五个 CJK 字素各用一个基准权重，逗号附着于前字并增加停顿权重；总权重归一化到 2.80 秒。第一字的视觉进度从 12.00 秒开始，下一句仍严格在 14.80 秒切换。第二句布局可在约 14.40–14.55 秒低亮预备，14.80 秒进入主焦点。若用户在 13.20 秒 seek，直接按 13.20 秒对应的估算字素显示，不播放 12.00 秒之后的动画补帧。

文案和代码注释应明确“行内进度为估算”。任何 UI 不得宣称此效果已获得逐词精准同步。后续若引入词级歌词数据，应作为独立、可选的数据源扩展，不属于本规格。

## 6. 播放状态与边界行为

| 场景                                        | 预期画面                                                                      |
| ------------------------------------------- | ----------------------------------------------------------------------------- |
| 正常播放且有 LRC                            | 按当前句布局，高亮随估算字素时间推进；背景微动，音频只轻推局部光场            |
| 暂停                                        | 冻结在当前歌词和字素位置；背景保留缓慢环境态，频谱响应归零                    |
| 正向 seek                                   | 立即跳到目标句/目标字素，再以短缓入方式衔接，不把未播放部分补成已唱           |
| 反向 seek                                   | 恢复目标时刻对应的等待/高亮/已唱状态，不保留旧方向余辉                        |
| 切歌或歌词更新                              | 清空上首歌的行布局、歌词光和时间缓存；新歌词进入后再平滑显示                  |
| 歌词播放中晚到                              | 保留环境光与曲目信息，按当前播放时间直接显示应有歌词状态；不补播已错过的歌词  |
| 首句开始前                                  | 曲名/艺人与环境光维持安静待机；只在首句预备窗口显出淡轮廓，不显示空白歌词容器 |
| 句间空隙                                    | 旧句退入远景；若有下一句，可低亮预告但不抢主焦点                              |
| 无歌词/纯音乐/歌词尚未加载/没有可解析时间戳 | 保留背景光场，显示曲名与艺人名及少量呼吸星点；不造曲名假歌词                  |
| 没有当前歌曲                                | 只显示安静环境光场，不显示旧歌曲文字                                          |
| 分析器不可用或无数据                        | 频谱驱动归零，歌词时间仍由播放时间正常推进                                    |
| 画布尺寸或 DPR 改变                         | 重算安全区和布局缓存；不改变当前音乐进度或歌词时间                            |
| 标签页隐藏                                  | 复用现有停止 RAF 的行为；回到前台时重设帧间隔，避免时间大跳                   |
| 减少动态效果                                | 保留布局和歌词进度，关闭微尘漂移、周期摆动和过强光闪，转场使用短淡化          |

当相邻行间空白超过约 0.9 秒时，旧句在交接淡化后保持为低对比文字轨迹，环境光接管视觉焦点；下一句只在预备窗口内进入远景。歌词有效行全部结束后，最后一句按受限尾长退远，不循环重播，也不把纯音乐片段渲染成空白字幕行。

## 10. 验收标准

### 视觉

1. 当前歌词不再只呈现为居中单行；有明显但不机械的错落短行结构。
2. 活动字素是第一视觉焦点，未唱字、过去歌词和装饰光场层级清楚；前后句可感知但不影响读字。
3. 柔光、字缘光晕、少量尘点与现有背景融为一体，不出现大量闪烁或同权重文本。
4. 中文、拉丁文、混排、标点、短句和长句均不裁字、不乱序，窗口缩放后构图仍稳定。
5. 无歌词画面只出现曲目信息和环境光场，不把标题渲染成假歌词。
6. 常规句入场/交接符合表中时长范围；短句不会因为动效延迟 LRC 行边界，前后句不会同时争夺主焦点。
7. 同一时间戳的重复/并发文字稳定显示，不因二分查找或重渲染随机消失；长空隙和尾句按远景/环境态收尾。
8. 系统开启减少动态效果后，光束摆动、尘点漂移和环境浮动停止，但歌词时钟与当前行可读性保留。

### 时间和状态

1. LRC 行切换仍按行时间进行；行内高亮平滑推进且始终限制在该行有效区间。
2. 暂停冻结文字进度；seek 和反向 seek 可立即恢复对应词/字状态，不残留前一播放方向的进度。
3. 切歌或更新歌词后不显示旧歌词；末句、解析失败、无歌曲、无分析器、页面隐藏等路径稳定。
4. 低音/高音变化只产生克制的局部光场响应；音频数据无效时响应归零，歌词同步照常。
5. 0.5×、1×、2×播放速度的字素估算都跟随实际歌曲时钟；暂停中拖动进度立即定位，不继续旧字余辉。
6. 密集行时间戳下任何字素高亮都不越过下一条有效行；晚到歌词从当前歌曲时间恢复，而不是从头补播。

### 兼容与资源

1. 保持 `cinematicLyricDrift` 效果 ID 和既有设置字段可读。
2. 不改变歌曲对象、localStorage/IndexedDB 数据格式或共享播放器行为。
3. 长时间逐帧渲染后离屏画布、纹理、缓存和粒子对象数量有界；少量即时渐变只随当前帧重建，不累积保留。
4. 30/60/120Hz 下文字入场、光晕和背景漂移的感知时长接近；页面切回首帧无时间跳变。
5. Home、Player、全屏歌词的源文件不在改动列表中。
