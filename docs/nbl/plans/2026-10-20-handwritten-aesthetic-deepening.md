# 「温光浮字」手书美学深化计划（第二轮）

> 日期：2026-10-20
> 范围：继续只改 `cinematicLyricDrift` 及其手书模块；不改效果 ID、设置字段、歌词/播放来源与 V7 核心视图。
> 背景：上一轮解决了卡顿与动画手感（镜头噪声、抬笔节奏、转场快照、确定性画质档位），但用户反馈「现在不是很美观」。本轮以真实手书/手账的视觉语言为参照，重做「纸、字、页面构成、转场」四件事，而不是继续加动效。
> 研究依据：handwriting-research.md（本地调研文档，原文在 gitignore 的 scratch/viz/ 下，未随仓库保留）（14 条来源、95 张参考图、逐条差距分析）。本文在其上做取舍与工程化拆解。

## 1. 调研结论：现在为什么不像「真实手书」

先给结论：**字体不是主因**（约占 10%）。按收益排序，四个问题拿走约 70% 的观感：

| 排序 | 问题                                              | 真实手书/手账的做法                                                                           |
| ---- | ------------------------------------------------- | --------------------------------------------------------------------------------------------- |
| 1    | 全页米黄底 + 棕色径向暗角 + 完美圆形光斑          | 中性浅白/浅灰纸（L\* 90–94），颜色只出现在「贴上去的纸/墨/印章」上；暗角是纸边投影 + 线性压暗 |
| 2    | 单一字重、单一字号、均匀字距、整行居中            | 逐字字号/基线/字距/旋转都有 3–6% 级抖动；主句/次句/边注三种字重；行末不齐                     |
| 3    | 元素均布：每页 1 胶带 + 4–5 涂鸦 + 1 印章，无投影 | 单页只有 1 个焦点簇（3–5 件元素互相重叠 20–40%），簇外大面积留白；每个实物都有纸面投影        |
| 4    | 旧句以 0.56α 大字号压在新句后面，两句话同时可读   | 旧句缩小、上移、褪成浅墨；换页用翻页/擦除/抬笔淡出，不做同位置双字叠化                        |

另外三条中级问题：涂鸦是与正文笔宽断档的 2px 均匀线（像 icon）；高亮是直角矩形色块；页饰是通用图标语言（邮票里画「山+太阳+方框」= 图片占位符）。

真实手书的六个可观察维度（来自日文手写字体资料与手账参考）：**墨积（ink pooling）、右肩上扬、歪字/潦草、多书体混排、纸感、边注/实物**。本轮全部参数化。

## 2. 可执行规则（R1–R14，全部可落到 Canvas 2D）

> `em` = 当前主句 fontSize（1920×1080 下主句约 88px）。

| 编号 | 规则           | 具体参数                                                                                                                                 |
| ---- | -------------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| R1   | 单页一个焦点簇 | 簇内 3–5 件元素重叠 20–40%；簇中心落在 (0.34–0.44, 0.42–0.56) 或镜像；簇外留白 ≥ 画面 35%；**不要正中**                                  |
| R2   | 中性纸色       | 纸底 L\* 90–94、chroma ≤ 0.03；paperLight/Base/Deep 三级明度差 ≤ 6%；彩色只给贴纸/墨/印章                                                |
| R3   | 投影层         | 每个「贴上去的东西」带 2–5px、右下偏移、α 0.12–0.22 软投影 + 0.5px 顶部亮边                                                              |
| R4   | 逐字随机       | fontSize ×0.92–1.10；基线 dy ±0.015–0.022em；横向 x ±0.008–0.012em；旋转 ±0.6–1.5°；整行累计漂移 ≤ 0.03em                                |
| R5   | 字重/笔压      | 主句 1.0、次句 0.5–0.6、边注 0.3–0.4；同字三叠印：主笔 + (+0.02em,+0.02em) α0.26–0.32 + (−0.015em,−0.02em) α0.12–0.16                    |
| R6   | 字距           | advance 抖动 ±4–6%；标点后 +0.10–0.14em；行末不齐；禁整行 textAlign center（逐字定位）                                                   |
| R7   | 墨色           | 主墨 L\* 22–30、chroma 0.02–0.05（偏棕/墨蓝）；逐字 α 0.84–1.0；写完 0.4–1.2s 保留湿墨；干后 2–5 个 0.5–1.5px 纸色飞白点                 |
| R8   | 纸面三层质感   | 纤维 ≥600 根/1920，偏水平、长 2–8px；絮团 6–10 处，半径 0.10–0.40H，α ≤0.05；污渍/折痕 1–2 处；纹理按 `width×dpr` 生成                   |
| R9   | 暗角/桌面      | 压暗总强度 ≤ 0.18；纸边→桌面过渡 ≥ 40px；桌面露出 ≤ 画面 6%；禁止棕色径向渐变，改纸边投影 + 四边线性压暗                                 |
| R10  | 页饰预算       | 单页 ≤ 2 件实物；胶带必须压住内容（纸边/字角），α 0.55–0.75、锯齿 1–2px、撕口 3–6px、旋转 ±4°；印章 ≤ 1，缺墨 15–30%；同类不重复         |
| R11  | 涂鸦预算       | 单页 ≤ 2 个，其中 ≥1 个指向文字（箭头/圈/引线/下划线）；线宽 = 主句笔宽 12–20%；roughness 2–4px@1920；每笔允许 2 处断笔；同页 ≤ 2 色     |
| R12  | 书写节奏       | 每字 duration = 行时长/字数 ×(0.6–1.6)；字间停顿 8–90ms；标点后 120–260ms；行末 200–400ms；起笔慢→行笔快→收笔慢；整页写完 ≤ 行时长 × 0.8 |
| R13  | 转场           | 只允许翻页/手擦除/抬笔淡出；禁止同位置双字 crossfade；zoom 1.00→1.03–1.05、rotate ≤ 0.6°、drift ≤ 1.5%                                   |
| R14  | 颜色预算       | 单页彩色 ≤ 2 色；彩色面积 ≤ 5%；强调色只出现在一个词 + 一处涂鸦；禁止纯白纯黑                                                            |

## 5. 实施计划

### P0（本轮）：纸、字、构成、转场

**P0-1 纸与色**

- `handwrittenPalette.ts`：5 套调色板 v2，纸底改中性浅色，提高墨/纸对比，强调色收敛（见 §6 参数表）；
- `handwrittenPaper.ts`：纸纹按 `width×dpr` 生成；暗角改「纸边投影 + 四边线性压暗」，总强度 ≤0.18；纸边过渡拉宽到 ≥40px；桌面露出 ≤6%；光斑改不规则水彩晕染；光泄漏强度减半。

**P0-2 字（收益最大）**

- 新增字形 sprite 图集：每个字按（字符、字号、字体、颜色、样式）烘焙一次，内含墨积、边缘渗墨、干笔飞白、三叠印；
- 逐字随机：字号 ±8%、基线 ±1.6px、横向 ±1px、旋转 ±1.2°、逐字 α 0.84–1.0；
- 字距 advance 抖动 ±5%，标点后额外空隙；行末不齐；
- 铅笔稿独立 sprite（更宽、更抖、更淡 ≤0.12α），不再与墨迹同形；
- 湿墨：写完 0.4–1.2s 保留暖色湿边 + 飞白；旧句缩小到 0.34×、α≤0.3、上移。

**P0-3 页面构成**

- 元素预算：歌词页 ≤2 涂鸦（1 个必须指向文字：箭头/圈/引线）+ ≤2 实物；器乐/间奏页可 ≤3；
- 焦点簇：第一件实物或涂鸦与文字块重叠 20–40%；簇外留白；
- 实物升级：胶带压纸边/字角并有撕口与投影；印章缺墨；邮票改「手写涂鸦 + 邮戳」不做图标插画；删除「图片占位符」式图标；
- 边注系统：日期、页码、天气/♪、一行小字批注（逐字小抖动）；
- 一个关键词放大 1.25–1.4× 作为视觉锚点。

**P0-4 转场与节奏**

- 去掉同位置双字叠化：outgoing 前 45% 淡出、incoming 55% 后淡入，中间用暖光扫过 + 极轻的"抬页"缩放；
- past 行不再大字号压层；
- 镜头 zoom 上限 1.04。

### P1（下一轮）

书写节奏细化（标点停顿、整页 ≤ 行时长 0.8）、涂鸦笔压 taper/断笔、水彩斑 sprite、安静分支 B、拍立得/票根等更多实物、竖排字距抖动与双列。

## 7. 验收标准

1. 视觉 rubric（对照真实手账参考逐项打勾）：纸底中性、无明显棕色滤镜、三层纸纹、暗角 ≤0.18、焦点簇、实物投影、胶带压内容、印章缺墨、无图标语言、逐字大小/基线/字距抖动可见、主句/次句/边注三档字重、旧句不压新句、转场无双字叠化。
2. 确定性：同一音乐时刻重绘/seek 像素级一致（沿用上一轮脚本）。
3. 性能：1080p 单次绘制中位数 ≤1.6ms、p95 ≤2.5ms；1920×1080@dpr4 压力场景 0 掉帧（沿用 `scratch/perf/measure.py`）。
4. 工程：effects 测试全绿、`tsc --noEmit`、ESLint 改动文件 0 error；临时 harness 删除。
5. 视觉抽查：片头/竖排/横排/间奏/片尾/移动端/超宽，无黑帧、无裁切、无异常。

## 8. 风险与取舍

- **页面会变"空"**：装饰预算下降 + 留白上升后，单页元素从 ~9 降到 4–5，第一眼可能显空。P0 必须同时调纸/字/焦点簇，不能只减元素；本轮保留 2 个涂鸦 + 2 个实物以维持信息量。
- **转场改法会改基线**：checkpoint 截图整体变化，`scratch/perf` 旧图仅作方向性对比，需重新截图归档。
- **内置字体是跨设备美观的最大单点风险**，但属于资源决策（+1–3MB），本轮不改字体栈，只做字形质感与随机化。
- **中文手书/日文手書き成品帧未能直接获取**（网络限制），R1–R14 的数值是可实施初值，后续有真实成品帧时应再校准 ±20%。
