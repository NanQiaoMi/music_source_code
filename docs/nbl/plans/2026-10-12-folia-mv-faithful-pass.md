# Folia 式歌词 MV 保真修正实施计划

> 状态：旧 Canvas 实现已完成静态验证，但用户视觉验收未通过；已被 WebGL MV 重做规格取代，不得继续作为目标实施计划。
>
> 新规格：[Folia 式 WebGL 歌词 MV 重做](../specs/2026-10-13-folia-webgl-mv-design.md)。
>
> 开发分支：`feature/folia-mv-faithful-pass`，从本地 `master` 的 `cd77068` 创建。实现代码在独立 worktree 中完成，之后按分支生命周期合并。

## 目标

把「温光浮字」重做为更接近 Folia 绘光式文字 PV 的连续画面：歌词成为镜头主体，灯场、线稿、前中后景与文字共同构图；歌词行进入局部窗口，以方向性字形运动和逐字光场点亮；器乐段与片尾分开，避免长段尾声提前显示静止标题卡。

保留效果 ID `cinematicLyricDrift`、现有 Canvas 2D 宿主、设置字段和 LRC 存储格式。没有真实逐字时间戳时，继续明确使用按行区间估算的视觉节奏；可用已有翻译 LRC 时把它作为字幕，不新增持久化字段或依赖。

## 任务拆分

### 任务 1：整曲时间线与段落转场

文件：`src/components/visualization/effects/lyricFilmProgram.ts`、`lyricFilmProgram.test.ts`。

- 长尾器乐先继续使用器乐镜头，片尾卡只占曲目末段约 7–8 秒；短尾声则按末句预估结束时间缩短。
- 同类相邻镜头用 0.35 秒轻柔焦点拉移衔接；灯灭/闪光等大转场只发生在场景类型边界。
- 覆盖长尾、短尾、无歌词、边界 seek、总时长短于片尾时长、零/异常时长和确定性重编译。

### 任务 2：舞台灯光与镜头空间

文件：`src/components/visualization/effects/lyricFilmStage.ts`、`lyricFilmStage.test.ts`。

- 保持固定预算和 Canvas 2D；增加前中后景、可辨识的 profile 灯位/几何线稿与镜头方向变化，不靠单纯增加粒子数量。
- 歌词安全区维持较低背景对比，同时灯束在周围场景与字形位置留下可采样的局部照度。
- seek 与重复渲染保持确定性；暂停时镜头/歌词定格但雾、灯和尘点保留低幅环境运动，reduced-motion 冻结这类运动。

### 任务 3：歌词窗口、字形轨迹和翻译字幕

文件：`src/components/visualization/effects/cinematicLyricDrift.ts`、`lyricFilmLyrics.ts`、对应测试，以及新建 `lyricFilmComposition.ts` 与测试。

- 把单一中心横排改为按镜头 profile/种子选择的局部构图：主句大字，邻句错位退后；少量中文/日文镜头用竖排槽位，其他维持易读横排。
- 按歌词估算单元和绝对音乐时间绘制入场轨迹、短暂余光；亮度采样舞台光场。当前音节/字组用暖金高光，未唱字接受冷色弱照，已唱内容留短暂余辉后退入雾中。
- 扩展有限前后歌词窗口，仍保留每条 LRC 源行独立，防止同刻行拼接或屏幕文字墙。
- 解析现有 `translationLyrics` LRC，在底部安全区显示与当前源行时间近邻对齐的翻译；缺失/错位时隐藏字幕。翻译分组只在切歌或译文变更时重建。
- 窄屏、防裁切、字号上限、缓存上限和减少动态效果持续成立。

### 任务 4：片尾卡片

文件：`cinematicLyricDrift.ts`、`lyricFilmComposition.ts` 及测试。

- 曲名延迟后逐字显影，艺人和已有专辑信息随后渐显；保持画面由器乐舞台过渡，不在整段长尾重复显示完整元数据。
- 片尾单元测试使用绝对音乐时间验证前进、暂停后同刻、seek 回退均给出同一帧。

### 任务 5：文档、验证与交付

- 更新设计规格与实施计划，明确哪些镜头和歌词时间为确定性估算。
- 运行 4 个聚焦测试文件、受影响文件 ESLint、Prettier、`git diff --check`、`npx tsc --noEmit --pretty false` 和生产构建；构建与 TSC 串行执行。
- 不操控当前 Chrome 播放实例；若不能取得不干扰用户播放的动态证据，最终写明动态歌词、seek 与暂停画面仍未核验。
- 两阶段全局审查后，在 `feature/folia-mv-faithful-pass` 提交；通过后 `--no-ff` 合并本地 `master`，合并后再回归。不推送。

## 验收

1. 常见宽屏画面能辨认出独立的场景层与灯位，歌词不再是固定中心文字叠背景装饰。
2. 中文歌词至少有横排与少量竖排/错位镜头；每个镜头同刻行仍独立，文字完整落在视口安全区。
3. 逐字显影稳定跟随音乐时间，当前字暖金、未唱字受局部冷光，seek 后同一时间仍得到相同构图。
4. 有翻译 LRC 时可显示对应字幕；没有时没有占位伪字幕。
5. 长器乐尾声只有末段进入片尾卡，片尾曲名逐字、艺人/专辑渐显；纯音乐与无歌词路径仍有舞台镜头。
6. 所有聚焦验证项记录实际命令与结果；静态构建不当作真实播放同步证据。
