# ADR 0005: 受保护视图的等价改写边界

- 状态: **Accepted（2026-10-29，D7；视觉基线按单一分辨率）**
- 日期: 2026-10-21（提议）/ 2026-10-29（批准）
- 关联: D7、S3-2/S3-3、S5-2
- 决策人: 用户（Lead 记录）

## 背景

- AGENTS.md/PROCESS.md 禁止修改 V7 核心视图（Home View / Player View / 全屏歌词）的视觉与交互。
- 但 page.tsx/GlobalClientComponents/HomeView/PlayerView 的整店订阅是重渲染主因；不触及这些文件无法完全清理。

## 决策（推荐，2026-10-21）

允许"仅订阅方式/调度门控"的等价改写（A）：

- 不改 JSX 结构、CSS、交互与文案；diff 只含 useEffect/selector/门控行；
- 改前改后截图对照 + Profiler/指标证据；
- Lead 逐文件复核，PR 描述引用本 ADR。
  禁止：布局重排、样式改版、行为变化、动画曲线调整。
  若否决，则 S3-2/S3-3 只能做 wrapper，E2/E3 目标下调。

## 决策（最终，2026-10-29 用户批准）

- **批准 A**：允许"仅订阅方式/调度门控"的等价改写，边界同上。
- **视觉基线口径**：接受**单一分辨率 1440x900 @1x** 的当前态截图作为基线（Home / Player / 全屏歌词 3 张 + `manifest.json` + `README.md`，见 `evidence/screenshots/s3-2/`）。
- **豁免**：计划原 1280x720 / 1920x1080 / 2560x1440 的改前/改后 pixel diff ≤0.1% 矩阵（本工作树无改前基线，用户 2026-10-29 接受单分辨率口径）。
- 截图由 `scripts/perf/capture-s3-2-screenshots.mjs`（`npm run perf:screenshots:s3-2`）复现。

## 影响

- S3-2/S3-3/S5-2 的订阅/调度改写合法化；S3-2 由"截图证据"升级为"接受基线"。
- 后续如改视觉，需以该 1440x900 基线为准重新截图。

## 验收（2026-10-29 口径）

- 单分辨率截图存在且可复现（3 视图 + manifest，PNG 均 <2 MB）。
- 交互行为与基线一致；diff 只含订阅/门控行。
- Profiler/指标证据见 S3-3/S3-4 记录（本 ADR 不重复采集）。

## 结果（2026-10-29）

S3-2 / S3-3 / S5-2 已按 A 完成；S3-2 记录"单分辨率基线 + 4 档 diff 豁免"偏差，用户同日接受。
